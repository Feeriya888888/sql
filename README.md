# Аналитика продаж интернет-магазина

Портфолио-проект по SQL: полноценная база данных интернет-магазина
и 10 аналитических запросов, каждый из которых отвечает на конкретный
бизнес-вопрос — от выручки по месяцам до поиска «спящих» клиентов.

## Стек
- **SQLite** (совместимо с PostgreSQL практически без правок)
- Оконные функции, CTE, агрегации, JOIN, условная логика CASE

## Структура проекта
| Файл | Что внутри |
|---|---|
| `01_schema.sql` | Схема БД: 4 таблицы, внешние ключи, индексы |
| `02_data.sql` | Тестовые данные: ~100 клиентов, 40 товаров, 600 заказов |
| `03_queries.sql` | 10 аналитических запросов с бизнес-комментариями |
| `data/orders.csv`, `data/customers.csv`, `data/products.csv`, `data/order_items.csv` | Те же данные в CSV — можно загрузить в любую СУБД |
| `results/` | Готовые результаты выполнения запросов (CSV) |

## Как запустить
1. Установите SQLite (или используйте любой SQL-редактор: DBeaver, DB Browser).
2. Выполните в терминале:
   ```
   sqlite3 shop.db < 01_schema.sql
   sqlite3 shop.db < 02_data.sql
   sqlite3 shop.db < 03_queries.sql
   ```

## Какие задачи решают запросы
1. ТОП-10 товаров по выручке
2. Динамика выручки по месяцам (LAG, оконные функции)
3. Сегментация клиентов по ценности (аналог RFM)
4. Доля отменённых заказов по месяцам
5. Средний чек по городам
6. Доля повторных покупателей (retention)
7. Выручка и доля категорий
8. Товары, которые часто покупают вместе (ассоциации)
9. «Спящие» клиенты для реактивации
10. AOV и число позиций в чеке по месяцам

## Что демонстрирует проект
- Проектирование реляционной схемы с нормализацией и ключами
- Написание сложных запросов: CTE, подзапросы, оконные функции
